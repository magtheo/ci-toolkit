EVIDENCE FIELDS (required for this review):

For every finding, include the "evidence" field required by the
response schema. For a finding with severity "blocking", "evidence"
must be an object with exactly these fields:

  "kind": one of
    "in_diff_behavior" - the harmful behavior is implemented in this
      diff
    "in_diff_contract_contradiction" - this diff contradicts a
      contract stated in this diff (docstring, comment, invariant)
    "external_fact" - the claim depends on a precisely checkable fact
      about a tool, CLI, framework, or API outside this diff
    "out_of_diff_assumption" - the harm depends on repository code,
      configuration, or workflows not shown in this diff
  "harm": one of
    "demonstrated" - the defect is established by the shown diff,
      optionally together with a precisely stated checkable external
      fact; it requires zero assumptions about unseen repository code
    "presumed" - the defect depends on unseen repository code,
      configuration, workflows, or another unverified condition
  "quote": the exact text from the cited file's diff that carries
    the harm (verbatim, minimal)

Constraints:
- "out_of_diff_assumption" is incompatible with
  "harm": "demonstrated"; if harm depends on unseen repository code,
  configuration, or workflows, use "presumed".
- "external_fact" may use "demonstrated" only when the external fact
  is precisely checkable and makes the shown code incorrect as
  written; otherwise use "presumed".
- Whole-change findings (no "line") must still quote from the cited
  file's diff.
- For a non-blocking finding, set "evidence": null.
- Do not change any other field of the output format.
